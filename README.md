## Tech Stack

- **Frontend:** React + Vite, Tailwind CSS
- **AI:** Google Gemini API (`@google/genai`)
- **Fonts:** IBM Plex Sans Arabic, Plus Jakarta Sans, Garet
- **Hosting:** Static site with SPA routing (`_redirects`)

## Repository Contents

This repository contains the **production build** of the site.

```
├── index.html          # Entry point
├── assets/             # Compiled JS and CSS bundles
├── fonts/              # Self-hosted Garet font files
├── SamahCV.pdf         # Curriculum vitae
├── portrait.png        # Profile photo / social share image
├── logo-en.png         # English logo
├── logo-ar.png         # Arabic logo
├── datathon-award.jpeg # Health Datathon award
└── _redirects          # SPA fallback routing
```

## Run Locally

```bash
npx serve -s .
```

Then open `http://localhost:3000`.

> **Note:** The AI assistant requires a Gemini API key, which is intentionally not included in this public repository.
